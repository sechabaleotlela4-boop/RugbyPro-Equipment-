# RugbyPro Equipment Store Website

## Project Overview

RugbyPro Equipment Store is a retail website project created for a rugby equipment business.

The website allows customers to learn about the organisation, view available rugby products, submit enquiries, and access contact information.

The purpose of this project is to create a simple and user-friendly online platform for rugby players, teams, schools, and supporters.

## Organisation Information

**Organisation Name:** RugbyPro Equipment Store

**Organisation Type:** Retail Business

**Industry:** Sports Equipment

RugbyPro provides rugby equipment including rugby balls, boots, jerseys, protective equipment, and training accessories.

## Website Goals

The goals of the website are:

- Create an online presence for RugbyPro Equipment Store.
- Allow customers to view rugby products.
- Provide product information.
- Allow customers to submit enquiries.
- Improve communication with customers.

## Target Audience

The website is designed for:

- Rugby players
- Rugby clubs
- Schools
- Coaches
- Parents purchasing equipment
- Rugby supporters
